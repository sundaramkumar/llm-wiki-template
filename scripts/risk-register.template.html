How to work through this list

  1. Start with Critical, then High (security and money first). For each one, open the wiki page and the cited code.
  2. Confirm it by reading the code path or writing a small test. Set the status to Confirmed or False alarm.
  3. For confirmed items, create a ticket and set the status to Ticket created. When it's fixed, set it to Fixed and run /wiki-sync so the wiki page drops the Risk note.
  4. Use Export CSV to import the list into Jira or share it with the team.

Statuses are saved in this browser only (local storage). Use Export CSV to share progress with others.
